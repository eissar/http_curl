Odin bindings for nghttp2, generated with karl-zylinski/odin-c-bindgen from the headers in input/ (copies of /usr/include/nghttp2/). Regenerate with `/tmp/bindgen.bin .` from this folder, then reapply the manual edit below, since regeneration overwrites it. Build the generator with `odin build src -out:/tmp/bindgen.bin -extra-linker-flags:"-L/usr/lib/llvm-19/lib -Wl,-rpath,/usr/lib/llvm-19/lib"`. Manual edit: in nghttp2.odin, change `NGHTTP2_PROTO_ALPN :: "\x2h2"` to `"\x02h2"` because Odin needs two hex digits in \x escapes; the bytes are the same. Check with `odin check . -no-entry-point`.
